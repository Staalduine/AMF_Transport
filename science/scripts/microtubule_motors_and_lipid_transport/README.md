# microtubule_motors_and_lipid_transport — figure scripts

`direction_rule_fig.py` draws the one schematic of `science/microtubule_motors_and_lipid_transport.typ`
into `science/figures/direction_rule.png`. Plain geometry, no data, so no number may be drawn into it.

    python3 direction_rule_fig.py

(In rhizosphere this ran through `doc.py --figs`, which does not exist here.)

Wrong answers that looked right: none yet. The first draft put two antiparallel microtubules on one line in
panel b, which read as a single track with a plus end in the middle; each track now has its own row.
